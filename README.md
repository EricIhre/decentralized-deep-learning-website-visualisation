# Decentralized Deep Learning – Website Visualisation

![Status: Work in progress](https://img.shields.io/badge/status-work%20in%20progress-orange)

> [!WARNING]
> **Work in progress.** This project is unfinished and under active development.
> Features may be incomplete, change without notice, or not work as expected.

A minimal, browser-based network visualisation of decentralized deep learning.

## Running locally

No build step is needed. Open `website/index.html` in a browser, or serve the folder:

```sh
cd website
python -m http.server 8000
```

Then visit http://localhost:8000.
